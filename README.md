# RunNet

RunNet is a Java-based running application designed to combine run tracking with run club communication.

## Current Features

- Runner profiles
- Run tracking
- Run history stored with ArrayLists
- Console-based testing application

## Planned Features

- Run club creation and management
- Club communication and messaging
- Route intelligence and trail information
- AI-assisted workout generation
- QR code club joining
- Auto-stop run functionality

## Technologies Used

- Java
- IntelliJ IDEA
- Git
- GitHub

## Project Status

RunNet is currently in active development as a learning and portfolio project.
