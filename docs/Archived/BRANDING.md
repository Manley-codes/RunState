RunState is the current working name for the app.

MoodPace is a strong alternate name to keep under consideration.

Previous name: RunNet

## Why RunState Fits

RunState connects to the app's core identity better than RunNet because the project is no longer focused on running plus networking.

The name can point to several parts of the app at once:

- Physical state after a run
- Mental state after a run
- Performance state, such as pace, distance, and personal records
- Context state, such as route, weather, shoes, or time of day
- Progress state over time

## Why MoodPace Fits

MoodPace may fit even better if pre-run and post-run feelings become a central part of the app.

The name connects two major sides of the project:

- Mood: how the runner physically and mentally feels before or after a run
- Pace: a core running metric that keeps the name clearly connected to running

Together, MoodPace suggests an app that connects how a runner feels with how they perform.

The main downside is that MoodPace can sound more focused on mood and pace than the full app. The app also tracks distance, personal records, route, and future context. Still, MoodPace is memorable and strongly matches the feeling-based direction.

## Brand Direction

The app should feel like a personal run tracker that helps runners understand how their runs are going, not just how far or how fast they ran.

The name supports the main idea that a run has more than one result. A run can have numbers, feelings, context, and patterns.

## Rename Notes

Keep both RunState and MoodPace in the docs for now.

The final app name, Java code, package names, project folder, and IntelliJ files can be renamed later when we are ready to do a careful cleanup.
